# RepoKeepers

RepoKeepers 是一个由社区驱动的开源项目延续与维护组织。

我们接纳因开发者退出、项目归档、平台下架或其他原因而停止维护的开源项目，帮助它们寻找新的维护者，并支持社区继续开发。

## 我们做什么？

- 项目接纳
- 持续维护
- 寻找维护者
- 项目延续

## 参与 RepoKeepers

任何人都可以参与，不需要提前加入组织。

你可以：

- 提名需要接手的开源项目。
- 为正在维护的项目提交 Issue 或 PR。
- 申请成为某个项目的 Maintainer。
- 帮助完善文档、项目目录和组织基础设施。

详细信息请参阅 [贡献指南](https://github.com/RepoKeepers/.github/blob/main/CONTRIBUTING.md)。

## 项目接纳

任何人都可以提名项目，管理员也可以主动发起提名。

项目经过初步评定和相应的社区决策流程后，可以进入维护中或寻求维护者的状态。

具体规则请参阅 [治理规则](https://github.com/RepoKeepers/.github/blob/main/GOVERNANCE.md)。
